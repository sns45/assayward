{{- if eq .Values.mode "audit" }}
=== AUDIT MODE (safe default) ===
The webhook is running in AUDIT mode. Pods are never blocked; deny-signals
appear as Kubernetes Warnings on the pod object. This lets you observe policy
violations before committing to enforcement (§3 audit-first rollout).

Watch audit warnings:
  kubectl get events -A --field-selector reason=Warning | grep assayward
  kubectl describe pod <pod-name> -n <namespace> | grep -A5 Warning

When you are satisfied with the policy coverage, flip to enforce mode:
  helm upgrade {{ .Release.Name }} {{ .Chart.Name }} \
    --reuse-values \
    --set mode=enforce \
    --set failurePolicy=Fail

{{- else if eq .Values.mode "enforce" }}
=== ENFORCE MODE ===
The webhook is running in ENFORCE mode. Pods whose images fail policy are
DENIED admission. Ensure you have observed the policy in audit mode first.

To revert to audit:
  helm upgrade {{ .Release.Name }} {{ .Chart.Name }} \
    --reuse-values \
    --set mode=audit \
    --set failurePolicy=Ignore
{{- end }}
